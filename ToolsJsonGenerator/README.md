# Tools.json Generator

🚀 **Complete AI Agent Tools.json Generator**

This tool provides a complete two-step pipeline that transforms your .NET Web API into a ready-to-use AI agent configuration:

**Step 1**: Extracts comprehensive endpoint metadata from compiled assemblies and XML documentation  
**Step 2**: Uses Google Cloud Vertex AI (Gemini) to transform the metadata into a properly formatted `tools.json` file that AI agents can use to interact with your API

The entire process is automated and runs during your build pipeline.

## 🎯 What This Does

### **Step 1: .NET Reflection Extractor**
1. **Loads your compiled .NET assembly** (DLL file)
2. **Reads XML documentation** generated by your build process  
3. **Discovers all API controllers** and their HTTP endpoints
4. **Extracts detailed metadata** including:
   - HTTP methods (GET, POST, PUT, DELETE, etc.)
   - Route patterns and full endpoint URLs
   - Method summaries and descriptions
   - Parameter types, names, and descriptions
   - Custom XML tags like `<example_uses>` and `<when_to_use>`
   - Authorization attributes
5. **Outputs structured JSON** metadata file

### **Step 2: AI-Powered Tools.json Generation**
1. **Reads the extracted metadata** from Step 1
2. **Sends to Google Cloud Vertex AI (Gemini)** with specialized prompts
3. **Transforms metadata** into properly formatted function definitions
4. **Generates tools.json** that AI agents can immediately use
5. **Outputs final configuration** ready for your AI service

## 🔧 Prerequisites

### **For Step 1 (Reflection Extraction):**
- **.NET 9.0 SDK** - [Download here](https://dotnet.microsoft.com/download/dotnet/9.0)
- **Compiled .NET Web API assembly** (your project's DLL file)
- **XML Documentation file** (automatically generated when `<GenerateDocumentationFile>true</GenerateDocumentationFile>` is enabled)

### **For Step 2 (AI Generation):**
- **Python 3.8+** - [Download here](https://python.org)
- **Google Cloud Project** with Vertex AI API enabled
- **Google Cloud Authentication** (via gcloud CLI or service account)
- **Python dependencies** (installed via `pip install -r requirements.txt`)

## 🚀 How to Run

### **🎯 Automated (Recommended)**

The entire pipeline runs automatically during your build process:

```bash
# Just build your project - everything happens automatically!
dotnet build UNOPS.PAO.Presentation
```

**What happens:**
1. ✅ **Step 1**: Extracts API metadata → `UNOPS.PAO.AIService/api-metadata.json`
2. ✅ **Step 2**: Generates tools.json → `UNOPS.PAO.AIService/tools.json` (if Python setup)

### **🛠️ Manual Setup (First Time)**

1. **Set up Python environment:**
   ```bash
   cd ToolsJsonGenerator
   setup.bat  # Windows
   # Or manually: pip install -r requirements.txt
   ```

2. **Configure for your environment:**
   ```bash
   # Option A: Quick setup with environment variables
   set GOOGLE_CLOUD_PROJECT=your-project-id
   set GOOGLE_CLOUD_LOCATION=us-central1
   
   # Option B: Use predefined environment files
   set-environment.bat dev  # or staging, production
   
   # Option C: Use gcloud CLI
   gcloud auth application-default login
   ```

3. **Build your project:**
   ```bash
   dotnet build UNOPS.PAO.Presentation
   # Or with explicit configuration:
   dotnet build UNOPS.PAO.Presentation -p:GoogleCloudProject=your-project-id
   ```

## ⚙️ Configuration

### **🎯 Automatic Environment Detection**

The system automatically detects and loads the appropriate environment configuration:

1. **Auto-Detection Logic**:
   - Checks `PAO_ENVIRONMENT` variable
   - Detects CI/CD environments (GitHub Actions, Azure DevOps)
   - Defaults to `dev` environment

2. **Environment Files**: Automatically loads from:
   - `ToolsJsonGenerator/environments/dev.env`
   - `ToolsJsonGenerator/environments/staging.env`

3. **Priority Order**:
   1. Command-line parameters (`--project`, `--location`, `--environment`)
   2. MSBuild properties (`-p:GoogleCloudProject=...`)
   3. Environment files (auto-loaded)
   4. Environment variables (`GOOGLE_CLOUD_PROJECT`, `GOOGLE_CLOUD_LOCATION`)
   5. Default values

## ⚙️ Setup Your Project for XML Documentation

Add this to your `.csproj` file to enable XML documentation generation:

```xml
<PropertyGroup>
  <GenerateDocumentationFile>true</GenerateDocumentationFile>
  <DocumentationFile>bin\$(Configuration)\$(TargetFramework)\$(AssemblyName).xml</DocumentationFile>
  <NoWarn>$(NoWarn);1591</NoWarn> <!-- Suppress missing XML comment warnings -->
</PropertyGroup>
```

## 📝 Enhanced Documentation Tags

The tool recognizes standard XML docs plus custom tags:

```csharp
/// <summary>Creates a new business partner in the system</summary>
/// <param name="model">Partner creation data with all required fields</param>
/// <returns>Created partner with assigned ID and metadata</returns>
/// <example_uses>
/// - Creating vendor partners for procurement processes
/// - Registering new implementation partners
/// - Adding supplier organizations to the system
/// </example_uses>
/// <when_to_use>When the AI agent needs to register a new partner organization</when_to_use>
[HttpPost]
public async Task<ActionResult<PartnerModel>> Create([FromBody] PartnerCreateModel model)
```

## 🔍 What Gets Extracted

✅ **Controllers**: All classes ending in "Controller" or with `[ApiController]`  
✅ **HTTP Methods**: GET, POST, PUT, DELETE, PATCH, etc.  
✅ **Routes**: Base routes from `[Route]` attributes and method-level routes  
✅ **Parameters**: Names, types, sources (body/query/route), and descriptions  
✅ **Documentation**: Summaries, parameter docs, return descriptions  
✅ **Custom Tags**: `<example_uses>`, `<when_to_use>`, and any other XML elements  
✅ **Attributes**: Authorization, validation, and other method attributes

## 🛠️ Troubleshooting

**Environment Configuration Issues:**
```bash
# Test your environment setup
python ToolsJsonGenerator/test_environment.py

# Check current environment variables
echo $GOOGLE_CLOUD_PROJECT (Linux/Mac)
echo %GOOGLE_CLOUD_PROJECT% (Windows)

# Force specific environment
dotnet build -p:PAOEnvironment=dev
```

**Google Cloud Authentication:**
```bash
# Set up authentication
gcloud auth application-default login

# Verify authentication
gcloud auth list

# Test with manual parameters
python llm_generator.py --project your-project --location us-central1 --environment dev
```

**Assembly Loading Errors:**
- Ensure all dependency DLLs are in the same folder as your target assembly
- Use absolute file paths for DLL and XML files
- Make sure the assembly targets .NET 9.0

**No XML Documentation Found:**
- Verify `<GenerateDocumentationFile>true</GenerateDocumentationFile>` is in your `.csproj`
- Check that the XML file exists in your build output folder
- Rebuild your project to regenerate documentation

**No Controllers Found:**
- Ensure your controllers inherit from `ControllerBase` or have `[ApiController]` attribute
- Verify your controllers have HTTP method attributes (`[HttpGet]`, `[HttpPost]`, etc.)

**Vertex AI Errors:**
- Ensure your Google Cloud project has Vertex AI API enabled
- Verify you're using the correct project ID and location
- Check your authentication with `gcloud auth list`
