OPPORTUNITY+ PROJECT KNOWLEDGE BASE
=====================================

## PROJECT OVERVIEW
Opportunity+ is a comprehensive partner and opportunity management system built for UNOPS (United Nations Office for Project Services). The system helps manage partnerships, contacts, notifications, and various business operations with role-based access control.

## USER ROLES AND PERMISSIONS

### 1. UNOPS_GEN_USER
- **Description**: General UNOPS user with read-only access
- **Permissions**: 
  - Can view all partners, contacts, and opportunities
  - Cannot create, update, or delete any records
  - Can search and filter data
  - Can access reports and analytics (read-only)
- **Use Cases**: Staff members who need to reference partner information but don't manage partnerships directly

### 2. PARTNER_GLOBAL_ADMIN
- **Description**: Global administrator with full system access
- **Permissions**:
  - Full CRUD (Create, Read, Update, Delete) operations on all entities
  - Can manage partners across all organizational units
  - Can assign roles and permissions to other users
  - Can access system configuration and settings
  - No organizational unit restrictions
- **Use Cases**: System administrators, global partnership managers

### 3. PARTNER_USER
- **Description**: Standard partner management user with organizational restrictions
- **Permissions**:
  - Can read all partner and contact information globally
  - Can create new partners and contacts
  - Can update/modify only records within their assigned org_unit
  - Can delete only records within their assigned org_unit
  - Cannot access system administration features
- **Use Cases**: Regional partnership officers, country office staff

### 4. ORG_UNIT_ADMIN
- **Description**: Organizational unit administrator with unit-specific management rights
- **Permissions**:
  - Can read all partner and contact information globally
  - Can create new partners and contacts
  - Can update/modify only records within their assigned org_unit
  - Can delete only records within their assigned org_unit
  - Can manage user permissions within their org_unit
  - Cannot access global system settings
- **Use Cases**: Country office managers, regional directors

### 5. GMAIL_GEN_USER
- **Description**: External user accessing Opportunity+ through Gmail add-on
- **Permissions**:
  - Limited access through Gmail integration
  - Can view partner information relevant to email context
  - Can search for contacts and partners
  - Cannot modify any data
  - Access is contextual based on email content
- **Use Cases**: External partners, consultants with Gmail integration

## ORGANIZATIONAL UNITS
- **Format**: Alphanumeric codes (e.g., B0002, A1001, C0045)
- **Purpose**: Organizational units represent different UNOPS offices, regions, or departments
- **Access Control**: Many operations are restricted based on user's assigned org_unit
- **Examples**:
  - B0002: Could represent a specific country office
  - A1001: Could represent a regional headquarters
  - C0045: Could represent a thematic department

## SYSTEM FEATURES

### Partner Management
- Create, view, update partner organizations
- Track partner relationships and classifications
- Manage partner documents and communications
- Handle due diligence and compliance

### Contact Management
- Maintain contact information for partner representatives
- Track communication history
- Manage contact roles and responsibilities

### Opportunity Management
- Track business opportunities and projects
- Link opportunities to partners and contacts
- Monitor opportunity lifecycle and status

### Notification System
- Real-time notifications for important updates
- Customizable notification preferences
- Integration with email and system alerts

### Search and Analytics
- Advanced search capabilities across all entities
- AI-powered similarity search for finding related partners
- Reporting and analytics dashboards
- Export capabilities for data analysis

## CONTEXT-AWARE ASSISTANCE

### URL-Based Context
The system provides context-aware assistance based on the current page:

- **/partnerships/partner**: Partner listing page - help with searching, filtering, creating new partners
- **/partnerships/partner/{id}**: Specific partner details - help with viewing details, updating information, managing relationships
- **/partnerships/contact**: Contact listing page - help with contact management and communication
- **/partnerships/contact/{id}**: Specific contact details - help with contact information and history
- **/notifications**: Notifications page - help with managing alerts and system notifications

### Personalized Responses
Responses are tailored based on:
- User's name and role
- Current organizational unit
- Page context and available actions
- User's permission level for suggested operations

## SECURITY AND COMPLIANCE
- Role-based access control (RBAC)
- Organizational unit-based data segregation
- Audit trails for all data modifications
- Integration with UNOPS authentication systems
- Compliance with UN data protection standards

- **Support Hours**: During UNOPS business hours

When users mention "contact support", "contact admin", "need help", or click support-related gems:

- Encourage them to include:
  - Detailed description of the issue
  - Steps to reproduce the problem
