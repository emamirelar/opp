IMPLEMENTATION NOTE
engineering Organigram — Possible Implementation Approaches
A PrimeNG OrganizationChart Recommended
Uses p-organizationChart with custom ng-template for UNOPS-styled nodes. Already in the codebase (used in partner org-structure dialog — currently WIP/commented out). Zero new dependencies. Built-in expand/collapse and selection events.
No new deps Existing pattern Table-based layout
B PrimeNG TreeTable For List View
Uses p-treeTable for the tabular/list toggle. Already in the codebase (partner-tree admin). Handles 150+ nodes well, with sortable columns (Name, Level, Type, Director, B-Code). Best for search and filtering use cases.
No new deps Existing pattern Performant at scale
C Mermaid.js Diagram
Uses mermaid ^11.8.0 — already installed. Generates crisp SVG with auto-layout. Quick to implement but limited node styling (no rich HTML inside nodes). Best as a read-only "poster view."
No new deps SVG output Limited interactivity
D Custom HTML/CSS Recursive Component
Build a custom app-office-organigram using recursive Angular templates — matching this mockup exactly. Full UNOPS design token control, lazy-load children on expand. More development effort but maximum design fidelity.
No new deps Pixel-perfect match More dev effort
recommend Recommended Approach: A + B Hybrid
Organigram view: Option A (PrimeNG OrganizationChart) with custom node templates styled to UNOPS tokens. Show top 2–3 levels by default, expand on click. Falls back to Option D if PrimeNG styling proves too rigid.
List view: Option B (PrimeNG TreeTable) reusing the partner-tree pattern. Better for search, filtering, and data-dense scenarios.
Both views share the same TreeNode[] data model. Zero new dependencies — uses only PrimeNG components already in the project.

The complete detail view of an Office record. The Details tab shows Key Information (identifiers, hierarchy, parent/child offices) and Geographic Implementation location data at the bottom. All other data — Financial, Scope, Roles & DoA, Related Opportunities, Related Partner Accounts, and Documents — lives in dedicated tabs alongside Details.
