Mockup Notes:

  • GMS Pattern: <app-requirements-validation> component from GMS:
    • Blue info panel (not a card) - #2996f3 text, #eaf6ff background, #b5dbff border
    • Only shows when requirements are NOT met - hidden when all pass
    • Shows ONLY unmet requirements - no checkmarks for met items
    • Collapsible header with info icon and chevron toggle
  • Header message: "The {entity} cannot proceed to the {nextStage} stage until the following conditions are met"
  • API Call: GET /api/workflow/opportunity/{id}/requirements?currentStage=IDENTIFY%20%26%20PROFILE
  • Submit button: Disabled until allRequirementsMet() returns true
  • Real-time validation: Form value changes trigger re-validation automatically
  • Server-side validation: DoA holder check uses onlyServerSideEvaluation: true
  • Stage panel: Separate <app-stage-workflow> component with Overview, Approvers*, History tabs
